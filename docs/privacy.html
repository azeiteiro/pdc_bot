Privacy Policy

Last updated — June 2026

This Privacy Policy outlines how the Music Festival Telegram Bot collects, processes, uses, and stores data, with a specific focus on the information accessed through Google API services.

Data Collected & Google API Usage

The Music Festival Telegram Bot requests permissions to integrate with external Google APIs to automate specific features for authorized users. The data collected includes:

  • Telegram User Data — Telegram user IDs and usernames are used strictly to identify and authenticate authorized users within the bot interface.
  • Logistics Information — User-submitted names, arrival/departure dates, and travel details are processed to coordinate event schedules.
  • Google Photos API — Media (photos and videos) shared directly within the application's authorized chat environment are uploaded automatically to an operator-controlled Google Photos album.
  • Google Sheets API — Financial expenses and onboarding responses inputted via command lines are logged directly to a secure Google Sheets spreadsheet.

How Data Is Used

All data processed by the Music Festival Telegram Bot is used exclusively to facilitate event coordination, logistics management, and media archiving for the application's users. Data obtained via Google APIs is never shared with third parties, sold, or used for tracking or commercial marketing purposes.

Data Storage & Security

Data persistence is managed securely across the following platforms:

  • A local SQLite database stores temporary user sessions and application states.
  • Google Sheets handles the storage of expense logs and structured onboarding parameters.
  • Google Photos holds uploaded media assets.

All infrastructure and access tokens are managed exclusively by the application administrator on a secure environment.

Third-Party Integrations

  • Telegram Bot API
  • Google Photos API
  • Google Sheets API
  • AccuWeather API

Each independent integration operates under its respective platform's privacy frameworks and developer agreements.
